# Agent contract

## Architecture

Backend-only FastAPI service following DDD layers. Dependencies point inward only:

```
interface (FastAPI, WebSockets) -> application (use cases, ports) -> domain (pure)
infrastructure (Postgres, Redis, FCM, JWT, APScheduler) -> application -> domain
```

- `src/nova/domain`: entities, value objects, domain events. No imports from FastAPI, SQLAlchemy, Redis, Firebase, APScheduler, or pydantic-settings.
- `src/nova/application`: use cases and `Protocol` ports. No framework types in public signatures.
- `src/nova/infrastructure`: adapters implementing the ports.
- `src/nova/interface`: HTTP/WebSocket adapters, request/response schemas, auth dependencies.
- `alembic`: generated migrations only; review every autogenerated migration before commit.

Never bypass a use case from a router. Never let infrastructure import from `interface`.

## Commands

```bash
uv sync
uv run ruff check . && uv run ruff format --check .
uv run mypy
uv run pytest
docker compose config
docker compose up --build
```

Add a test for every new use case or invariant. OpenAPI is generated from FastAPI routes; never hand-edit it. Use Conventional Commits (`feat(reminder): ...`, `fix(auth): ...`). Never commit secrets, `.env`, `secrets/`, or real FCM/JWT credentials.
